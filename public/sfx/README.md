# Efectos de sonido (SFX) — opcional

Suelta aquí dos efectos cortos `.mp3` que suben mucho la sensación de producción pro:

| Archivo | Cuándo suena | Env var |
|---|---|---|
| `whoosh.mp3` | en cada transición de escena | `SFX_WHOOSH_URL=https://sagaia.vercel.app/sfx/whoosh.mp3` |
| `impact.mp3` | golpe de apertura sobre el hook (primer segundo) | `SFX_IMPACT_URL=https://sagaia.vercel.app/sfx/impact.mp3` |

Son opcionales: si no existen, el video se renderiza igual sin ellos.
Consíguelos gratis en Pixabay / YouTube Audio Library (descarga y sube aquí, no hotlink).
